# Individual-level carrier tools

These optional source-derived tools were restored at the user's request. They produce individual sample identifiers, genotype-group membership, controlled BAM paths, and optional IGV instructions.

They are code only; no real inputs or outputs are included. Use them exclusively in an approved controlled-data environment. Keep every generated table, log, image, and batch script outside Git. Review all placeholder paths and the locally configured special-case BAM naming policy before execution.
