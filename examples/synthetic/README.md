# Synthetic count-matrix example

The example data are entirely synthetic and are provided only to demonstrate file formats and command usage. They cannot reproduce the results reported in the associated study.

`CASE001` and `CTRL001` are invented identifiers. Coordinates, gene names, transcript names, and coverage values are also invented and do not correspond to study participants or observed variants.

Run the command shown in the root README from the repository root. Generated output belongs in `demo_output/`, which is ignored by Git.
